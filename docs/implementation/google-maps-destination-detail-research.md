# Nghiên cứu: Google Maps JavaScript API cho bản đồ trang chi tiết điểm đến

Kế hoạch này là lịch sử: implementation Google Maps JavaScript API đã được thay bằng iframe không key cho Detail theo ADR-22 (2026-10-26).

Ngày nghiên cứu: 2026-10-25. Phạm vi đề xuất chỉ là `/destinations/[id]`, gồm nhánh chi tiết thường và các khối bản đồ Editorial. Home tiếp tục dùng iframe hiện tại; Explore, Admin picker, Trip và các bản đồ khác giữ nguyên trong công việc này. Đây là nghiên cứu và kế hoạch, chưa phải implementation hay bằng chứng runtime.

## Hiện trạng trong repository

- `apps/web/src/app/destinations/[id]/destination-detail.tsx` dùng `DestinationMap` ở nhánh chi tiết thường. Khi có Editorial đã xuất bản, trang chuyển sang `EditorialRenderer`; khối `MAP` của `apps/web/src/components/editorial/editorial-story.tsx` và `apps/web/src/components/editorial/editorial-generative-renderer.tsx` cũng dùng `DestinationMap`. Chuỗi HTML người dùng cung cấp có `aria-label="Bản đồ tham chiếu ..."`, tương ứng với khối Editorial, nên chỉ thay nhánh thường sẽ không sửa được trang đang xem. [Nguồn repository: `destination-detail.tsx`](../../apps/web/src/app/destinations/%5Bid%5D/destination-detail.tsx), [`editorial-story.tsx`](../../apps/web/src/components/editorial/editorial-story.tsx), [`editorial-generative-renderer.tsx`](../../apps/web/src/components/editorial/editorial-generative-renderer.tsx).
- `DestinationMap` hiện là component dùng chung, gọi `mapStyle()` của Stadia và `mountMapLibre()`. Nó cũng phục vụ Explore; sửa provider bên trong component dùng chung sẽ kéo theo thay đổi ngoài phạm vi trang chi tiết. [Nguồn repository: `destination-map.tsx`](../../apps/web/src/components/map/destination-map.tsx), [`map-config.ts`](../../apps/web/src/modules/map/map-config.ts).
- `map-model.ts` xuất tuple `[longitude, latitude]` cho MapLibre. Google Maps JavaScript API nhận `position` và `center` theo object `{lat, lng}`; cần chuyển rõ ràng từ `latitude` và `longitude`, không truyền tuple cũ. [Nguồn repository: `map-model.ts`](../../apps/web/src/modules/map/map-model.ts), [Google: Add a marker](https://developers.google.com/maps/documentation/javascript/advanced-markers/add-marker).
- US-12 ghi nhận Google prototype cũ đã bị thay bằng MapLibre/Stadia do chưa cấu hình được billing. US-13 ghi nhận trang chi tiết dùng bản đồ chia sẻ đó. Việc dùng Google riêng trên Detail là một ngoại lệ kiến trúc mới so với ADR-19; khi triển khai cần ghi quyết định được chấp nhận và cập nhật story/progress hiện hành, không viết lại lịch sử. [US-12](../stories/US-12-destination-map.md), [US-13](../stories/US-13-destination-detail.md), [`decisions.md`](../decisions.md).

## Điều Google xác nhận

| Chủ đề | Kết luận có nguồn |
| --- | --- |
| Iframe và marker | Maps Embed API chính thức đặt pin cho một `place` theo `q`; nó không cung cấp cách điều khiển marker ứng dụng bằng JavaScript trong iframe. URL iframe không key đang dùng ở Home là dạng khác với endpoint Embed API chính thức; không dùng nó làm nền cho marker Detail. [Google: Embed a map](https://developers.google.com/maps/documentation/embed/embedding-map). |
| API tương tác | Maps JavaScript API tạo bản đồ và `AdvancedMarkerElement` đặt marker tại `{lat, lng}`. Thư viện `marker` được tải riêng; Google yêu cầu map ID cho Advanced Markers. `DEMO_MAP_ID` chỉ dành cho thử nghiệm; Production phải dùng map ID của project. [Google: Add a marker](https://developers.google.com/maps/documentation/javascript/advanced-markers/add-marker), [Get started](https://developers.google.com/maps/documentation/javascript/advanced-markers/start). |
| Tải API | Google hỗ trợ dynamic library import hoặc gói npm `@googlemaps/js-api-loader` v2 (`setOptions`, `importLibrary`). Tải thư viện khi component client được mount và tránh lặp bootstrap/script trên cùng trang. [Google: Load the Maps JavaScript API](https://developers.google.com/maps/documentation/javascript/load-maps-js-api). |
| Marker tương tác | `gmpClickable: true`, `title` và sự kiện `gmp-click` hỗ trợ chuột và bàn phím; `InfoWindow` có thể neo vào marker. Detail hiện mở popup tên/khu vực/loại điểm, không có liên kết tự dẫn về chính trang; giữ hành vi này với một marker Google. [Nguồn repository: `maplibre-renderer.ts`](../../apps/web/src/modules/map/maplibre-renderer.ts), [Google: Accessible markers](https://developers.google.com/maps/documentation/javascript/advanced-markers/accessible-markers), [Info Windows](https://developers.google.com/maps/documentation/javascript/infowindows). |
| Key và chi phí | Maps JavaScript API cần API key và billing. Lượt tải map dùng SKU Dynamic Maps; kiểm tra bảng giá/quota tại thời điểm bật Production, không coi đây là iframe miễn phí. [Google: Set up](https://developers.google.com/maps/documentation/javascript/get-api-key), [Usage and billing](https://developers.google.com/maps/documentation/javascript/usage-and-billing). |
| Giới hạn key | Browser key xuất hiện trong request/client dù được đặt ở `NEXT_PUBLIC_` env, vì vậy dùng key riêng cho web, giới hạn **Websites/HTTP referrers** cho `http://localhost:3010` và các origin deploy thực tế; xác nhận mẫu referrer được Google Cloud Console chấp nhận bằng smoke browser, không dựa vào đường dẫn trang vì trình duyệt có thể chỉ gửi origin. API restriction chỉ cho Maps JavaScript API. Không dùng khóa routing/server hiện có cho browser. Không commit giá trị hoặc log full URL chứa key. [Google: Security guidance](https://developers.google.com/maps/api-security-best-practices), [Google Cloud: Manage API keys](https://docs.cloud.google.com/docs/authentication/api-keys). |
| Theme/attribution | Google hỗ trợ light/dark `colorScheme` khi khởi tạo và hỗ trợ cloud map styles theo map ID; xác nhận tính tương thích style cụ thể trong browser. Giữ attribution mặc định của Google hiển thị rõ, không vẽ đè hoặc tự thay nhãn Stadia. [Google: Map color scheme](https://developers.google.com/maps/documentation/javascript/mapcolorscheme), [Maps JavaScript policies](https://developers.google.com/maps/documentation/javascript/policies). |
| Lỗi | Key, billing, quota hoặc referrer sai có thể tạo bản đồ tối với thông báo development hoặc lỗi trong console. Tải script thành công không đủ để kết luận tile và marker render; cần smoke trên browser và giữ UI lỗi/thử lại hiện có. [Google: Troubleshooting](https://developers.google.com/maps/documentation/javascript/troubleshooting), [Error messages](https://developers.google.com/maps/documentation/javascript/error-messages). |

## Kế hoạch triển khai đề xuất

1. Chủ project bật Maps JavaScript API và billing, tạo browser key bị giới hạn như trên, tạo JavaScript map ID thật. Khai báo `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY` và `NEXT_PUBLIC_GOOGLE_MAPS_MAP_ID` trong env schema/example, không ghi giá trị. Hai biến này là cấu hình browser; không dùng `STADIA_MAPS_API_KEY` hoặc khóa server. Map ID là bắt buộc cho Advanced Markers. [Google: Advanced Markers setup](https://developers.google.com/maps/documentation/javascript/advanced-markers/start).
2. Tạo component client riêng cho **một điểm đến ở Detail**, tải Maps JS theo nhu cầu và nhận dữ liệu tọa độ công khai đã qua projection/validation. Map center và Advanced Marker cùng dùng `{lat: latitude, lng: longitude}`; click hoặc Enter mở InfoWindow chỉ với tên/khu vực/loại điểm, không tự liên kết về cùng trang. Giữ kích thước, nhãn truy cập, loading/error/retry và không làm thay đổi API/DTO/visibility của Detail. Khi unmount hoặc retry, bỏ marker/listener và không để một map cũ phủ lên map mới. [Google: Add/remove marker](https://developers.google.com/maps/documentation/javascript/advanced-markers/add-marker), [Accessible markers](https://developers.google.com/maps/documentation/javascript/advanced-markers/accessible-markers).
3. Chuyển cả ba điểm gọi thuộc Detail sang component mới: nhánh thường trong `destination-detail.tsx`, `MapSection` của Editorial V1, khối MAP của Editorial V2. Giữ nguyên `DestinationMap`, `map-config.ts` và MapLibre cho Explore/consumer khác. Vì `apps/web/src/app/layout.tsx` import MapLibre CSS toàn cục, CSS đó có thể vẫn được tải trên Detail dù không còn MapLibre runtime; việc tách CSS toàn cục là công việc riêng nếu có yêu cầu “không một asset MapLibre nào”. [Nguồn repository: `layout.tsx`](../../apps/web/src/app/layout.tsx).
4. Cập nhật test đúng ranh giới: Detail thường và Editorial V1/V2 render Google component với một marker/tọa độ đúng; thiếu tọa độ thì không tạo map; hidden/unavailable không phát dữ liệu; thiếu key/map ID/lỗi tải giữ thông báo và retry. Không sửa business logic hoặc test Explore trừ khi phát hiện tác động thật.
5. Smoke URL người dùng cung cấp ở light/dark và màn hình hẹp: có một Google map, đúng một marker tại Cao nguyên đá Đồng Văn, attribution Google rõ; không có DOM `.maplibregl-*`, request tile Stadia hoặc script/worker MapLibre phát sinh từ Detail. Kiểm tra Network và console cho lỗi key/referrer/quota/tile, không chỉ nhìn map container; thử trạng thái lỗi/thử lại bằng cấu hình thiếu trong môi trường kiểm thử. Kiểm tra Explore vẫn hoạt động độc lập. Sau đó chạy focused tests, typecheck, `git diff --check`, kiểm tra không có giá trị key trong diff/log.

Các file dự kiến: component mới `apps/web/src/components/map/google-destination-detail-map.tsx`; ba consumer nêu ở bước 3; CSS scoped cho Detail trong `components/map/map.css` hoặc stylesheet Detail; `apps/web/.env.schema`, `.env.example` và generated `src/env.ts`; test Detail/Editorial và cấu hình env. Ghi ngoại lệ Google Detail vào `docs/decisions.md` và cập nhật US-13/progress khi implementation được kiểm chứng. Không sửa `map-config.ts`, renderer MapLibre, routing, dữ liệu DB hay Home.

**Điều kiện trước smoke thành công:** owner cung cấp key/map ID hợp lệ trong env cục bộ và cấu hình Google Cloud tương ứng. Không dùng `DEMO_MAP_ID` làm cấu hình Production. Chưa triển khai trong tài liệu này.
